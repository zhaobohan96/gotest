# 围棋官子练习 - 功能文档

## 项目概述

围棋官子练习网站，用于训练官子目数计算能力。基于 WGo.js 实现棋盘渲染，支持 SGF 格式题目文件。

---

## 功能模块

### 1. 棋盘显示模块

| 功能 | 说明 |
|------|------|
| SGF 解析 | 解析 SGF 文件中的 AB（黑子）、AW（白子）、TR（三角标记）属性 |
| 棋盘渲染 | 使用 WGo.js 渲染 19x19 棋盘，支持坐标显示 |
| 响应式 | 棋盘大小随窗口自适应（最大 640px） |
| 三角标记 | TR 属性标记官子位置 |

**关键函数：**
- `parseSGFProperty(content, propName)` - 解析 SGF 属性值
- `loadSGF(sgfContent)` - 加载并渲染 SGF 到棋盘
- `syncBoard()` - 同步棋盘状态

---

### 2. 答案输入模块

| 功能 | 说明 |
|------|------|
| 输入格式 | 支持整数（`2`）和带分数（`2又1/3`） |
| 属性选择 | 先手/后手/逆收 三个单选项 |
| 格式校验 | 自动校验输入格式，提示错误 |

**关键函数：**
- `parseAnswerValue(str)` - 解析答案字符串为数值
- `formatAnswer(value)` - 将数值格式化为分数显示
- `gcd(a, b)` - 计算最大公约数
- `simplifyFraction(num, den)` - 约分分数

---

### 3. 答案检查模块

| 功能 | 说明 |
|------|------|
| 数值比较 | 浮点数容差比较（0.001） |
| 属性匹配 | 必须同时匹配数值和性质（先手/后手/逆收） |
| 字符串比较 | 字符串类型答案使用精确匹配 |

**关键函数：**
- 答案检查逻辑在 `submitBtn` 点击事件中
- 比较方式：`Math.abs(userAnswer - answerValue) < tolerance`

---

### 4. 导航模块

| 功能 | 说明 |
|------|------|
| 上一题/下一题 | 按顺序切换题目 |
| 随机一题 | 随机选择题目（排除当前题） |
| 题号跳转 | 输入题号直接跳转 |
| 键盘导航 | 左右方向键切换题目 |

**关键函数：**
- `loadProblem(index)` - 加载指定索引的题目
- `searchByNumber()` - 按题号搜索跳转

---

### 5. 练习模式

| 模式 | 说明 |
|------|------|
| 自由练习 | 顺序/随机浏览题目，显示正确率统计 |
| 测试模式 | 随机抽题测试，结束后显示成绩 |

---

### 6. 难度分级

| 级别 | 题数 | 说明 |
|------|------|------|
| 初级 | 76题 | 入门级官子计算 |
| 中级 | 114题 | 进阶级官子计算 |
| 高级 | 43题 | 高难度官子计算 |

---

### 7. 测试模式

| 功能 | 说明 |
|------|------|
| 难度选择 | 测试前选择难度 |
| 题数选择 | 10题/20题/30题 |
| 随机抽题 | 打乱题目顺序 |
| 答题统计 | 实时显示正确率 |
| 结果弹窗 | 测试完成后显示总题数、正确数、错误数、正确率 |

---

### 8. 数据存储

| 数据 | 说明 |
|------|------|
| index.json | 题目索引（题号、文件名） |
| answers.json | 答案数据（数值、性质、先手方） |
| localStorage | 统计数据持久化 |

**答案数据格式：**
```json
{
  "1": {"answer": 6, "property": "gote"},
  "2": {"answer": "2又1/3", "property": "sente", "turn": "w"}
}
```

---

### 9. 响应式设计

| 断点 | 布局变化 |
|------|----------|
| > 960px | 水平布局（棋盘+侧边栏） |
| 640-960px | 垂直布局，侧边栏水平排列 |
| < 640px | 紧凑布局，隐藏副标题 |
| < 380px | 最小化布局 |

---

### 10. UI 交互

| 功能 | 说明 |
|------|------|
| 模式切换 | 自由练习/测试模式 |
| 难度切换 | 自由模式可切换，测试模式禁用 |
| 答案显示 | 显示/隐藏答案按钮（测试模式隐藏） |
| 进度条 | 显示当前题号/总题数 |
| 反馈提示 | 正确/错误/提示三种状态 |
